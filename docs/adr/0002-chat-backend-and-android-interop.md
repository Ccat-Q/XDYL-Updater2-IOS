# 本地实现独立聊天后端，并在持钥客户端兼容旧安卓

已接受，2026-10-19；补充 [ADR-0001](0001-chat-v2-before-ios-migration.md)。用户随后批准实现后端完整功能，并明确要求旧安卓与新前端直接互聊；因此“只写文档”不再是本轮范围，但不部署线上服务，也不提前实现 iOS 页面。

选择 D1 原子批次承载消息、事件、幂等与 outbox，私有 R2 承载客户端加密历史分块。相比仅保留两个不互通的版本，新增显式旧协议兼容主设备和客户端双协议编解码；相比在中继解密转码，不持有私钥，避免破坏端到端加密。代价是旧协议消息只能由持钥主设备解密，跨旧安卓曲线不互通，已有旧私钥不得被新版静默覆盖。设备迁移与备份恢复另走客户端加密流程，不能用重发历史伪造新消息。

后端本地验证通过不等于生产部署、安卓 APK 真机联调或 iOS 交付；上线门槛和剩余风险见[整改记录](../CHAT_SERVER_REMEDIATION.md)。
