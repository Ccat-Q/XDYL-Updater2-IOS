# 可靠性验收前暂缓 iOS 私聊迁移

状态：已接受；日期：2026-10-19。接受的是本项目迁移边界，聊天 V2 协议仍为未实现、待维护方评审的建议。

后续范围调整：用户已批准本地实现后端及旧安卓互通，见 [ADR-0002](0002-chat-backend-and-android-interop.md)。下文保留最初决策背景；iOS 真机和线上验收门槛仍保留，不再以“只文档”描述当前工作区。

源项目 V1 存在认证不一致、分页漏信、单公钥算法冲突和无真实已读等问题。相比直接移植或在原接口不断叠加兼容字段，我们选择保留旧接口、提出独立版本化 V2，并在服务端可靠性验收通过前暂缓 iOS 在线私聊。这样不会为了兼容旧行为把漏信和密钥覆盖风险固化进新客户端；代价是当前不交付聊天功能，旧 Android 也需升级才能获得 V2 能力。

本次只提交文档，不修改或部署服务端、不发送真实凭证联调。Bark 接入由在线服务触发，只记录在整改方案中；不通过 iOS 后台轮询替代推送。范围与门槛见[服务端整改方案](../CHAT_SERVER_REMEDIATION.md)。
