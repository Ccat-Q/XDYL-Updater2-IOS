## 验证与边界

协议测试使用 URLProtocol 替身，不发送线上扣费、授权或对局请求。只读核验已确认市场预览/历史和 Windows 默认 YSM 历史服务可达。QQ 302、YSM 上传/授权、支付渠道配置及真实对局结果仍需测试账号进行设备端联调。不把服务端尚未配置的支付或不可达的服务伪装为成功。

Windows 的本地 mods/tacz 增量安装、启动器目录清理和 EXE 自更新按既有 iOS 边界适配为下载至“文件”App 与下载可重签 IPA；它们不是手机端游戏安装器。
