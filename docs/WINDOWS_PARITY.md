# Windows 功能适配记录（2.2.0）

参考 EXE：`ModUpdater2（2）.exe`，SHA-256 `59a7b5dc6e79b578ef40c1130b0a30c982ee901aecfeaa430fe915295fc6291e`。

## 已实现

- 统一 HTTP/业务错误、令牌刷新合并、过期会话恢复、正确的图片 multipart 和 MIME。
- QQ 未绑定关联、密码重置、简介/完整游戏资料、用户名修改、游戏绑定和玩家公开资料。
- 社区分页、分类请求竞态保护、定向回复、表情库/上传、图片顺序/HTML、写入和图片上传进行中保护。
- 投票选项与改投、领奖资格、保留其他任务类型、购买/领奖后余额刷新、称号正确请求体与短色码/长度校验。
- 市场预览/价格历史、兑换码、喵币兑换、支付宝订单/支付结果、爱发电查询/兑换、意见删除。
- 决斗真实字段、账号在线状态、竞技场时间、邀请有效期/轮询、确认倒计时、返回前台同步与提交锁。
- 整合包直链/网盘入口、YSM 兑换码/玩家/公开表单、重复授权确认、上传历史与模型结果。
- 下载 HTTP 校验、任务取消/重试、后台恢复、唯一文件名、读取错误传播和后台文件处理。
- 开发者目录覆盖已恢复接口，并提供请求体示例、文件字段和附加 multipart 字段。

## 验证与边界

协议测试使用 URLProtocol 替身，不发送线上扣费、授权或对局请求。只读核验已确认市场预览/历史和 Windows 默认 YSM 历史服务可达。QQ 302、YSM 上传/授权、支付渠道配置及真实对局结果仍需测试账号进行设备端联调。不把服务端尚未配置的支付或不可达的服务伪装为成功。

Windows 的本地 mods/tacz 增量安装、启动器目录清理和 EXE 自更新按既有 iOS 边界适配为下载至“文件”App 与下载可重签 IPA；它们不是手机端游戏安装器。
